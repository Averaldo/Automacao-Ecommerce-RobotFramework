Projeto de automação de testes de E-commerce utilizando Robot Framework e Selenium

Pré-requisitos: pip, robot framework, webdriver e biblioteca Selenium
Links de download: https://www.python.org/downloads/ https://chromedriver.chromium.org/dow... 

Comandos: 
pip --version (Para consultar versão do pip)
pip install robotframework (Para instalar o Robot) 
pip install robotframework-seleniumlibrary (Para instalar o selenium library)
Comando de execução: robot e-commerce.robot
